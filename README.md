# bogyman-web

Landing page for Bogyman, a single-binary CLI that tells you which of your
Claude Code and Codex sessions is waiting on you, and why.

Plain static site: `index.html`, `style.css`, `main.js`, `bogyman.svg`.
No build step. Deployed to GitHub Pages from the `main` branch.

To preview locally:

```sh
python3 -m http.server 8080
```

then open http://localhost:8080.
